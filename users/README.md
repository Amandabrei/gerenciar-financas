# gerenciar-financas

Projeto criado para desafio Beca NttData, gerenciamento de finanças.

## Executando o ambiente

Para iniciar o banco de dados e, futuramente, os micros-serviços:

```bash
docker compose up --build
```

Para iniciar somente em segundo plano:

```bash
docker compose up -d
```

Para parar os containers:

```bash
docker compose down
```
